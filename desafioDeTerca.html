🛒 Desafio: Desconto no E-commerce

Objetivo: Criar uma lógica que calcule o valor final de um produto aplicando um cupom de desconto.

⚠️ A Missão:
Se o cupom for "DESC10", o preço deve ter 10% de desconto.
Se for "DESC20", o preço deve ter 20% de desconto.
Se não for nenhum cupom válido, o preço continua o mesmo (sem desconto).

💡 Dica: Multiplicar por 0.8 dá 20% de desconto, e se não houver cupom, o preço final é igual ao original.

📘 Explicação

Trabalhar com operadores condicionais e cálculos matemáticos básicos é uma das tarefas mais comuns no dia a dia de um programador front-end.

if (cupom === "DESC10") {
  precoFinal = preco * 0.9;
} else if (cupom === "DESC20") {
  precoFinal = preco * 0.8;
} else {
  precoFinal = preco;
}
